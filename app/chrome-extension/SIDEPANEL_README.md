# SidePanel 功能说明

## 概述

这个Chrome扩展现在包含了一个新的SidePanel功能，允许用户通过点击按钮打开一个固定的侧边栏窗口。

## 功能特性

### 1. 侧边栏按钮
- 在popup窗口中添加了一个"打开侧边栏"按钮
- 按钮具有渐变背景和悬停效果
- 点击后会在右侧弹出SidePanel窗口

### 2. SidePanel窗口
- **固定位置**: 从右侧滑入，覆盖整个屏幕高度
- **响应式设计**: 在移动设备上会占满整个屏幕宽度
- **动画效果**: 包含淡入和滑入动画

### 3. 功能模块
- **快速操作**: 包含打开聊天、刷新状态、设置等按钮
- **系统状态**: 显示连接状态和服务器状态
- **最近活动**: 显示时间戳和活动记录

### 4. 状态同步
- SidePanel会实时显示popup中的系统状态
- 支持刷新状态功能
- 可以直接从SidePanel打开聊天面板

## 使用方法

### 打开SidePanel
1. 点击Chrome扩展图标打开popup
2. 点击"打开侧边栏"按钮
3. SidePanel会从右侧滑入

### 关闭SidePanel
1. 点击右上角的关闭按钮(×)
2. 或者点击SidePanel外的半透明区域

### 功能操作
- **打开聊天**: 点击"打开聊天"按钮，会关闭SidePanel并打开聊天面板
- **刷新状态**: 点击"刷新状态"按钮，会刷新连接和服务器状态
- **设置**: 点击"设置"按钮（功能待实现）

## 技术实现

### 组件结构
```
SidePanel.vue - 主要的侧边栏组件
├── 头部区域 (标题 + 关闭按钮)
├── 内容区域
│   ├── 快速操作按钮
│   ├── 系统状态显示
│   └── 最近活动列表
└── 样式和动画
```

### 状态传递
- 通过props从App.vue传递系统状态
- 通过emit向父组件发送事件
- 支持双向数据绑定

### 样式特性
- 使用CSS Grid和Flexbox布局
- 响应式设计，支持移动端
- 平滑的CSS动画和过渡效果
- 现代化的UI设计风格

## 配置要求

### Manifest权限
需要在`wxt.config.ts`中添加`sidePanel`权限：
```typescript
permissions: [
  // ... 其他权限
  'sidePanel', // 添加侧边栏权限
]
```

### 组件导入
在`App.vue`中导入SidePanel组件：
```typescript
import SidePanel from './components/SidePanel.vue';
```

## 扩展功能

### 可以添加的功能
1. **更多操作按钮**: 如导出数据、导入配置等
2. **实时通知**: 显示系统事件和警告
3. **快捷设置**: 快速修改常用配置
4. **历史记录**: 显示操作历史
5. **帮助文档**: 集成使用说明

### 自定义样式
可以通过修改CSS变量来调整主题色彩：
```css
:root {
  --primary-color: #8b5cf6;
  --secondary-color: #64748b;
  --background-color: #f8fafc;
}
```

## 注意事项

1. **性能**: SidePanel使用固定定位，不会影响页面性能
2. **兼容性**: 支持现代浏览器，使用CSS Grid和Flexbox
3. **响应式**: 在不同屏幕尺寸下都能正常显示
4. **可访问性**: 包含适当的ARIA标签和键盘导航支持

## 故障排除

### 常见问题
1. **SidePanel不显示**: 检查是否正确导入了组件
2. **样式异常**: 确保CSS文件正确加载
3. **状态不同步**: 检查props传递是否正确

### 调试方法
1. 使用浏览器开发者工具检查元素
2. 查看控制台是否有错误信息
3. 检查Vue组件是否正确渲染
